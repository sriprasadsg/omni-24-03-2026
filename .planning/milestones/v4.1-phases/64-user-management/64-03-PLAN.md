<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → LDAP Endpoints | Admin-only config; untrusted input for LDAP config |
| LDAP Service → LDAP Server | Service account credentials; TLS required for production |
| LDAP Service → MongoDB | User provisioning with source="ldap" flag |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-64-07 | Spoofing | LDAP authentication | high | mitigate | TLS/StartTLS required; bind with user credentials; validate server cert |
| T-64-08 | Tampering | LDAP config | high | mitigate | Admin-only endpoints; encrypt sensitive fields (bind password) in DB |
| T-64-09 | Elevation of Privilege | Group-to-role mapping | high | mitigate | Admin-only mapping management; validate role exists in rbac_service.default_roles |
| T-64-10 | Information Disclosure | LDAP user sync | medium | mitigate | Only sync required attributes; no password hashes from LDAP; tenant isolation |
| T-64-11 | Tampering | LDAP injection | medium | mitigate | Use ldap3 parameterized queries; validate/sanitize all user inputs in filters |
| T-64-12 | Elevation of Privilege | Local password for LDAP users | high | mitigate | Block local password change for users with source="ldap" (Pitfall 4) |
| T-64-SC | Tampering | npm/pip/cargo installs | high | mitigate | slopcheck + blocking human checkpoint for [ASSUMED]/[SUS] packages |

</threat_model>
