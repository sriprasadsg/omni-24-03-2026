## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-64-13 | Spoofing | SAML assertion validation | critical | mitigate | Signature verification, audience check, timestamp validation, ID replay cache (Pitfall: SAML assertion replay) |
| T-64-14 | Tampering | SAML config | high | mitigate | Admin-only endpoints; encrypt SP private key in DB |
| T-64-15 | Elevation of Privilege | Attribute/role mapping | high | mitigate | Admin-only mapping management; validate role exists in rbac_service.default_roles |
| T-64-16 | Information Disclosure | SAML user provisioning | medium | mitigate | Only map required attributes; no sensitive data from assertions; tenant isolation |
| T-64-17 | Elevation of Privilege | Local password for SAML users | high | mitigate | Block local password change for users with source="saml" |
| T-64-18 | Tampering | XML/SAML parsing | high | mitigate | Use python3-saml library (not custom XML parsing); disable DTD/external entities |
| T-64-SC | Tampering | npm/pip/cargo installs | high | mitigate | slopcheck + blocking human checkpoint for [ASSUMED]/[SUS] packages |
