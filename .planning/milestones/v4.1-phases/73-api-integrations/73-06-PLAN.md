## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser console → `POST /api/itam/tickets` | Operator-selected entity id and provider cross into a privileged outbound action |
| ticketing config response → console rendering | A response derived from a document holding third-party credentials reaches the browser |
| `ticket_url` value → anchor href | A value written by a third-party integration is placed into a navigable link |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-73-32 | Information Disclosure | provider availability derivation | medium | mitigate | Only two booleans are derived from the config response; no field of it is rendered, stored in component state beyond those booleans, or logged. The backend config route already masks credentials, and this plan does not weaken that (Task 2) |
| T-73-33 | Spoofing | provider value sent from the console | medium | mitigate | The provider is a two-member TypeScript union originating from a fixed two-item menu, never a text input; the backend independently constrains it with a literal type, so the console is not the only guard (Tasks 1, 2) |
| T-73-34 | Tampering | outward ticket link | low | mitigate | The anchor opens in a new tab with the noopener-noreferrer relationship, so the provider's page cannot reach back into the console window (Task 2) |
| T-73-35 | Denial of Service | repeated ticket creation from the console | medium | mitigate | The action is replaced by the ticket-reference display once a reference exists, so the console offers no second-ticket path; the backend's dedup guard and its conflict response are the authoritative enforcement (Task 2, plan 73-04) |
| T-73-36 | Repudiation | operator cannot tell a creation failed | low | mitigate | Failure drives the contract's error toast and restores the pre-click state, so the absence of a ticket reference is unambiguous (Task 2) |
| T-73-SC | Tampering | npm/pip/cargo installs | high | accept | Zero new frontend packages — the design contract is explicit that no component library, icon library, or dropdown dependency is introduced, and both icons already exist in the project's own icon module |
</threat_model>
