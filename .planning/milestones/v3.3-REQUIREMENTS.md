# Requirements: v3.3 — Agent Geo & Fleet Observability (ARCHIVED)

**Milestone goal:** Turn the agent public-IP/GeoIP data landed in v3.2 into a full geo + observability surface — a live fleet map, location-based security detections, health/uptime observability, and an immutable location-history audit trail. Offline-first (air-gapped safe) throughout.

**Shipped:** 2026-07-30. 4 phases (46–49), 23 plans. Audit: passed (see `v3.3-MILESTONE-AUDIT.md`). All 11 requirements met.

> Note: v3.3 requirements were tracked per-phase in ROADMAP.md, not in the root `REQUIREMENTS.md` (a known tooling sync gap). Extracted here at completion for the historical record.

## Location-History Audit (GAUD) — Phase 46

- [x] **GAUD-01**: Every agent public-IP/geo change is written to an append-only `agent_location_history` collection, change-detected cheaply off the already-fetched agent doc (cloned from `remediation_escalations`), with a NAT-flip de-noise state machine, per-tenant toggle, ASN/VPN enrichment (GeoLite2-ASN + bundled X4BNet heuristic), and 365-day retention through the existing retention module.
- [x] **GAUD-02**: A per-agent location-history timeline view (read-only, tenant-scoped GET with read-time dwell), mounted in the agent Overview tab, plus per-tenant privacy toggle in the Privacy Dashboard.

## Agent-Scoped Geo Security Detectors (GSEC) — Phase 47

- [x] **GSEC-01**: Heuristic VPN/proxy/hosting flag via GeoLite2-ASN + X4BNet, surfaced on the agent card and labeled explicitly as a heuristic — never an authoritative "detected" claim.
- [x] **GSEC-02**: Agent-scoped impossible-travel alert (haversine + time window, keyed by `agent_id`), fanned out through the existing `persist_security_alert` notification path — not a parallel channel.
- [x] **GSEC-03**: Per-tenant allowed-region geo-fence, alert-only (no blocking), with admin-gated GET/PATCH config endpoints and a security-settings panel.

## Fleet Observability (FOBS) — Phase 48

- [x] **FOBS-01**: CPU/memory/disk history charts off the existing metrics-history endpoint via recharts (Metrics tab in AgentDetailModal).
- [x] **FOBS-02**: Per-agent heartbeat/uptime timeline + selectable-range (1h/6h/24h/48h) uptime %, backed by daily uptime rollups.
- [x] **FOBS-03**: Fleet-level offline-agent and version-drift admin view (`GET /api/fleet/observability`), gated by `manage:agents`.

## Fleet Geo Map (GMAP) — Phase 49

- [x] **GMAP-01**: Fleet map with markers by city/country, self-contained bundled SVG basemap + equirectangular projection — no external tile servers (air-gapped). (Ships the graticule backdrop fallback; a public-domain land outline can be dropped in later.)
- [x] **GMAP-02**: Marker clustering (client-side grid buckets) + filter by tenant and by agent status.
- [x] **GMAP-03**: Marker click drills into agent identity, LAN/public IP, resolved location, and current status — reading the cross-tenant `GET /api/fleet/geo` projection.
