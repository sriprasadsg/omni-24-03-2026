## Phase Details

### Phase 64: User Management
**Goal**: Users can authenticate and manage accounts securely.
**Depends on**: Nothing
**Requirements**: ITAM-USR-01, ITAM-USR-02, ITAM-USR-03, ITAM-USR-04, ITAM-USR-05, ITAM-USR-06
**Success Criteria**:
  1. User can create, edit, delete user accounts.
  2. User can be assigned RBAC roles.
  3. User can authenticate via LDAP/AD and SAML/SSO.
  4. User can manage API access tokens.
  5. User can enable/disable 2FA.
**Plans**: 7 plans
**UI hint**: yes

Plans:
- [ ] 64-01-PLAN.md — User CRUD with ITAM fields, tenant isolation, admin gating (ITAM-USR-01)
- [ ] 64-02-PLAN.md — RBAC extension with ITAM roles, fixed normalization, super-admin guard (ITAM-USR-02)
- [ ] 64-03-PLAN.md — LDAP/AD integration: config, auth, user sync, group-to-role mapping (ITAM-USR-03)
- [ ] 64-04-PLAN.md — SAML/SSO: metadata, ACS, SLO, assertion validation, provisioning (ITAM-USR-04)
- [ ] 64-05-PLAN.md — API token management: lifecycle, scopes, expiration, rate limits (ITAM-USR-05)
- [ ] 64-06-PLAN.md — 2FA: TOTP enroll/verify, backup codes, disable, fixed pitfalls (ITAM-USR-06)
