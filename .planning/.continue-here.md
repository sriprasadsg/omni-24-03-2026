## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|-----------------------|
| `git commit -m ... -- <pathspec>` still commits the FULL current diff of the file, not just the intended hunks | Hit this twice this session (once on the very first commit sweeping in unrelated `frontend/`/orphan-module deletions, once on `agent_rust_builder.py` sweeping in an unrelated uncommitted Linux-build-pipeline feature). Pathspec restricts *which files* are committed, not *which hunks within a file* — if the file has other unstaged/uncommitted content, it all goes in. | advisory | After any commit in a repo with other known-dirty content in the same files, run `git show <new-commit> --stat` / `--` and confirm the diff matches intent before moving on. If it doesn't: `git reset --soft HEAD~1`, restore the file to `HEAD` via `git show HEAD:path > path`, reapply only the intended edit, recommit. |
