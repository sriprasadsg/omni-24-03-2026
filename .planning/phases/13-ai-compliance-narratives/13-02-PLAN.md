<objective>
Fix two post-execution defects discovered during phase verification:

1. **Event-loop ordering bug (AI-05/AI-06 test reliability)**: 5 async tests in
   `test_compliance_narrative_service.py` use `asyncio.get_event_loop().run_until_complete()`.
   In Python 3.12, `asyncio.run()` (used by `test_scheduled_reports.py`) removes the
   current event loop on completion. When `test_scheduled_reports.py` runs first
   (e.g., `pytest tests/test_scheduled_reports.py tests/test_compliance_narrative_service.py`),
   the 5 async tests fail with `RuntimeError: There is no current event loop in thread
   'MainThread'`. Replace with `asyncio.run(run())` which creates its own independent
   event loop per call.

2. **500-line violation in scheduled_reports_service.py**: The file is 539 lines, exceeding
   the 500-line limit in CLAUDE.md. The try/except ImportError guard (4 lines) plus the
   enrich_report_data gate and _render_narratives calls pushed the file over. Extract the
   scheduler loop body into a helper function `_process_due_schedule` to reduce line count
   while preserving all behaviour.

Purpose: Both fixes are CLAUDE.md compliance and test-reliability defects, not functional
regressions. All AI-05 and AI-06 behaviours are already implemented and verified —
this plan makes the verification proofs robust and the codebase rule-compliant.

Output:
- backend/tests/test_compliance_narrative_service.py (5 asyncio.run() replacements)
- backend/scheduled_reports_service.py (inline scheduler loop body extracted to helper, under 500 lines)
</objective>

        """Generate, deliver, and log one due schedule. Never raises — all exceptions logged."""
        try:
            sched_tenant_id = schedule.get("tenant_id", "")
            report_data = await _generate_report(schedule, sched_tenant_id)
            filename = await _deliver_report(schedule, report_data, sched_tenant_id)
            await _write_delivery_log(db, schedule, "success", None, filename)
            next_run = _calculate_next_run(
                schedule.get("frequency", "weekly"),
                schedule.get("send_at_hour", 8),

            await db.report_schedules.update_one(

                    "$set": {
                        "last_run": now,
                        "next_run": next_run.isoformat(),
                        "last_error": None,
                    },
                    "$inc": {"run_count": 1},
                },
            )
            logger.info(
                "[Reports] Delivered scheduled report '%s' for tenant %s",

            )
        except Exception as exc:
