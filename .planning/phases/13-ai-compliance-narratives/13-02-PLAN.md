1. **Event-loop ordering bug (AI-05/AI-06 test reliability — D-fix-1)**: 5 async tests in
   `test_compliance_narrative_service.py` use `asyncio.get_event_loop().run_until_complete()`.
   In Python 3.12, `asyncio.run()` (used by `test_scheduled_reports.py`) removes the
   current event loop on completion. When `test_scheduled_reports.py` runs first, the
   5 async tests fail with `RuntimeError: There is no current event loop in thread
   'MainThread'`. Replace with `asyncio.run(run())` which creates its own independent
   event loop per call.

   Exact lines to change in test_compliance_narrative_service.py:
   - Line 38: TestGenerateExecutiveSummary.test_returns_str_on_success
   - Line 63: TestWordBudget.test_trims_to_150_words
   - Line 85: TestFallbackOnError.test_returns_fallback_on_error_prefix
   - Line 110: TestFallbackOnBlocked.test_returns_fallback_on_blocked_prefix
   - Line 165: TestFrameworkNarrative.test_framework_narrative_within_200_words

2. **500-line violation in scheduled_reports_service.py (D-fix-2)**: The file is 539 lines,
   exceeding the 500-line limit in CLAUDE.md. Extract the scheduler loop body
   (lines 512-536 inside `start_report_scheduler`) into a helper function
   `_process_due_schedule` to reduce line count while preserving all behaviour.

Purpose: Both fixes are CLAUDE.md compliance and test-reliability defects, not functional
