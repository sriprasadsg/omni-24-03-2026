<objective>
Close CHK-02: replace the CloudFormation "not yet implemented" stub in iac_scanner_service.py with a real regex rule engine at rule-count parity with the existing Terraform/Kubernetes rules, and fix the pre-existing _detect_provider() bug that silently misclassifies YAML-format CloudFormation templates (the more common authoring style, and one the dashboard explicitly advertises) as "unknown" — which would otherwise prevent the new rules from ever firing.

Purpose: The existing IaC engine is provider-agnostic by design; CFN support means (a) adding 18 rule dicts in the exact existing shape, (b) fixing YAML CFN detection, and (c) deleting the dead early-return stub so CFN flows through the shared dispatch. This is disciplined imitation of the existing Terraform pattern — no new parser, no new scan function, no new dependency (RESEARCH.md Don't Hand-Roll).

Output: 18 CFN rules in IAC_CHECKS, a fixed _detect_provider(), a removed stub branch, and a CFN + detection + ReDoS test suite.
</objective>
