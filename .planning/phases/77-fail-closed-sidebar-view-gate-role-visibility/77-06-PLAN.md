Make custom tenant roles assignable everywhere a built-in role is (D-04): user create and update, Super Admin tenant moves (D-18), and the LDAP and SAML group mappings, always resolved inside the target tenant and always behind the existing ceiling.

Output: role_assignment.resolve_assignable_role, edits to user_endpoints, ldap/saml mapping services and endpoints, backend/tests/test_custom_role_assignment.py.
</objective>
