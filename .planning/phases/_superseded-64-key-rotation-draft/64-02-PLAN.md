    - `check_key_strength(key_path: &Path)`: Reads the key file, determines its type and properties (e.g., RSA key length, DSA key length). Classify keys as "weak" if they use deprecated algorithms or insufficient key lengths (e.g., RSA &lt; 2048, DSA &lt; 1024).
