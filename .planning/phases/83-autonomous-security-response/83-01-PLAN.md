Prove the path before any breadth: one IP address flagged by two different origins on one host becomes one automatic, gate-decided block, the agent's own verify result marks it verified, and an operator's undo removes only that claim.

Purpose: this is the first code that acts on its own. The largest risks (hostname versus agent id, a verify path that would lift a good block, an undo that removes another claim) sit on this one path, so they are settled here.
Output: the agent contract file, the sweep runner, the signal store, the dispatcher, the verify step and the undo claim, with one end-to-end test on the real database.
</objective>
