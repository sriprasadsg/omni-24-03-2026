<objective>
Fix the broken alert fan-out that GSEC-02 and GSEC-03 depend on. `ueba_service.py` defines a private `async def _persist_alert(...)` but never exposes the public `persist_security_alert` name that five existing heartbeat call sites (`shadow_ai`, `ueba_anomaly`, `fim_violation`, `pii_detected`, `runtime_security`) already `from ueba_service import persist_security_alert` inside `try/except ImportError: pass`. Because the name does not resolve, all five have silently no-op'd since they were written. This plan adds the public alias so the fan-out actually fires.

Purpose: Make the "existing alert fan-out" the phase must reuse real and importable. This is a strict prerequisite — the Plan 47-03 heartbeat wiring cannot call `persist_security_alert` until it exists. Fixing it also reactivates five dormant alert paths.
Output: A public `persist_security_alert` symbol in `ueba_service.py` plus a regression test proving importability and functional equivalence.
</objective>
