1. Per router object (each `_load(app, module, attr)` call): if all its routes are user-authenticated and none is self-service or app-shell, add one MOUNTS entry; otherwise add route-level dependencies=[Depends(catalogue_guard(...))] to each user route and catalogue_exempt(reason) to each self-service/app-shell route. 7. No service restarts, deploys, or writes to the live omni_platform database.
