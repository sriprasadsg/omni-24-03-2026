**What the researcher found that contradicts it** (recorded in `58-RESEARCH.md` → Package Legitimacy Audit; presented as evidence, not as an override):
- `pypi.org/pypi/python-barcode/json` reports `project_urls.repository = "https://github.com/WhyNotHugo/python-barcode"`, so the `no-repository` signal looks like a detection gap — the seam appears not to read `project_urls`.

**Why it is worth adding at all:** Code128 encoding carries a symbol table and a checksum that are easy to get subtly wrong in a way that produces a barcode which looks correct and scans as garbage.
