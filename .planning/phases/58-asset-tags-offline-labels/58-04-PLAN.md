Define the Avery 5160 constant block with a comment block citing the source: `PAGE_W, PAGE_H = letter`; `LABEL_W = 2.625 * inch`; `LABEL_H = 1.0 * inch`; `COLS = 3`; `ROWS = 10`; `LABELS_PER_PAGE = COLS * ROWS`; `TOP_MARGIN = 0.5 * inch`; `LEFT_MARGIN = 0.3125 * inch`; `COL_PITCH = 2.75 * inch`; `ROW_PITCH = 1.0 * inch`. Record in that comment that the outer margin is the arithmetically reconciled `(8.5 - 3 * 2.625) / 2`, that Avery's published figures agree on label size, grid and pitch but not on a single stated outer-margin number, and that confirming it to better than a sixteenth of an inch requires printing onto real label stock — logged as this phase's one manual-only verification.

Define `label_cell_origin(index_on_page: int) -> tuple[float, float]` returning the bottom-left corner of cell `index_on_page` (0-based, 0 to `LABELS_PER_PAGE - 1`) in reportlab's bottom-left-origin coordinate space: column is `index_on_page % COLS`, row is `index_on_page // COLS`, `x = LEFT_MARGIN + col * COL_PITCH`, `y = PAGE_H - TOP_MARGIN - (row + 1) * ROW_PITCH`. Raise `ValueError` for an out-of-range index. This function is the only place the grid arithmetic exists — the renderer and the geometry test both read it, so the test cannot pass against arithmetic the renderer does not use.

Define `label_draw_boxes(x: float, y: float) -> dict[str, tuple[float, float, float, float]]` returning `(x, y, width, height)` rectangles keyed `qr`, `barcode`, `tag`, `name` and `model` for a cell anchored at `(x, y)`. Choose an inner padding of about 0.05in, a square QR box of about 0.85in on the left, a barcode box occupying the remaining width in the upper right, and three stacked text bands beneath the barcode. Every returned rectangle must lie inside the cell; that is the property the geometry test asserts, and it is the mitigation that stops an unusually long asset name from bleeding into the adjacent label.

Define `_fit_text(text, font_name, font_size, max_width) -> str`: return the longest prefix of `text` whose `pdfmetrics.stringWidth` fits `max_width`, appending three ASCII period characters when truncation occurred and re-measuring so the result including them still fits. Measure rather than counting characters — a fixed character budget breaks for wide glyphs, which is exactly the input a caller controls through the asset name.

Define `generate_label_sheet_pdf(assets: list[dict]) -> bytes`. Raise `LabelEncodingError` when `assets` is empty — an empty request is a caller mistake and must not become a zero-page PDF that looks like a successful render. Create one `io.BytesIO` and one `canvas.Canvas(buf, pagesize=letter)`. Iterate with `enumerate`; compute `page_i = i % LABELS_PER_PAGE`; call `c.showPage()` only when `i > 0 and page_i == 0`, so no blank leading page is emitted; get the cell origin from `label_cell_origin(page_i)` and the rectangles from `label_draw_boxes`.

Per asset: read the tag with `asset.get("assetTag")` and raise `LabelEncodingError` naming that asset's `id` when it is missing or empty — the sheet must never contain a label with a blank code. Call `generate_qr_png(tag)` and `generate_barcode_png(tag)`, letting their `LabelEncodingError` propagate with the asset id added to the message. Wrap each PNG in its own fresh `io.BytesIO` and its own `ImageReader`, and append both readers to a local list that stays alive until after `c.save()` returns — reportlab reads image data lazily, so a shared or prematurely collected buffer renders blank on later labels rather than failing loudly. Draw both with `c.drawImage(..., mask="auto")` into their respective rectangles, using `preserveAspectRatio=True` for the barcode so a wide code is not distorted.

Then draw the D-01 text: the tag in Helvetica-Bold at about 7pt, the name and the model in Helvetica at about 6pt, each passed through `_fit_text` with its band's width, and each coerced with a pattern that turns a missing field into an empty string rather than the text `None` — read the field, treat a falsy value as empty, and only then stringify. Finish with `c.save()` and return `buf.getvalue()`.
