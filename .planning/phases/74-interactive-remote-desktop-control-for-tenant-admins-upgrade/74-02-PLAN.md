<objective>
Give the control session a backend life cycle: an append-only audit trail, a real kill switch
that reaches the live WebSocket instead of only the database, an authenticated route for the
agent to report the endpoint user's consent decision, and an authoritative answer to "may this
user control this endpoint" for the frontend to gate its affordance on.

Purpose: D-09/D-10/D-11 all promise that a control session can be ended, and D-12 promises a
dropped tunnel does not silently resume. None of those promises can be kept by a Mongo write —
the live connection state lives entirely in `tunnel_endpoints.py`'s module-level `_tunnels` dict.
This plan closes that gap and makes every transition auditable.

Output: `control_session_audit_service.py`, `close_session()`, and three new REST routes.
</objective>

First, `POST /session/{session_id}/consent`, authenticated with `Depends(verify_agent_key)` from
`backend/agent_auth.py` — the agent already holds the registration key it sends as `X-Tenant-Key`
on the tunnel, so this reuses an existing credential rather than opening a second auth path.

Second, `GET /capabilities`, gated only with `Depends(get_current_user)`. Call
`rbac_utils.verify_permission` twice, once for `view:remote_access` and once for
`control:remote_access`, and return both results as `can_view` and `can_control`. This is
deliberately a 200-with-false rather than a 403: the frontend needs an answer it can render a
toggle from, and the alternative — mirroring the permission table client-side — is unreliable
here because `App.tsx` intersects `currentUser.permissions` with the tenant's `enabledFeatures`

the client. The server is the only source of truth this affordance can trust. Enforcement stays
where it already is, on `start_remote_session` and the disconnect route; this probe only decides
whether an affordance is drawn.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → API (disconnect, capabilities) | An authenticated tenant user, possibly of another tenant, asks to end a session or learn its rights |
| agent → API (consent report) | A process on a remote endpoint asserts what the human at the keyboard chose |
| API → `_tunnels` | A REST handler reaches into live in-memory WebSocket state |
| API → audit collection | The immutable record of who did what |
