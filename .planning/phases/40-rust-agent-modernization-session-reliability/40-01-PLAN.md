| T-40-02 | Tampering | agent self-update binary download | accept | Already mitigated by existing unmodified code: agent_update.rs validates the downloaded response is a real Windows PE (MZ header + >1MB) and downloads are Bearer-token-authenticated (cfg.agent_token).
