## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-71-01 | Tampering | Purchase Order create/update | high | mitigate | Input validation on all fields (e.g., `order_number` format, `total_cost` positive, `order_date` valid datetime). RBAC enforcement (only authorized users can create/update). |
| T-71-02 | Information Disclosure | Purchase Order list/detail | medium | mitigate | Tenant isolation enforced by `ItamProcurementService` and FastAPI dependencies to prevent cross-tenant data access. |
| T-71-03 | Repudiation | Purchase Order creation | low | mitigate | Audit logging for all creation/update actions will be handled by the existing Phase 70 audit trail (ITAM-DAT-02). |
| T-71-04 | Tampering | Asset-PurchaseOrder link | medium | mitigate | Validate `purchase_order_id` refers to an existing Purchase Order within the same tenant. RBAC on asset updates. |
| T-71-SC | Tampering | npm/pip/cargo installs | high | mitigate | slopcheck + blocking human checkpoint for [ASSUMED]/[SUS]. |
