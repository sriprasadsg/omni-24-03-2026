<objective>
Build `agent_asn_service.py` — the heuristic ASN + VPN/hosting-flag lookup module that Phase 47's security detectors and this phase's location-history rows depend on. It is a file-for-file clone of `geoip_service.py`'s lazy-singleton `.mmdb`-reader pattern (D-11), plus a second lazy-loaded resource: a bundled X4BNet public-VPN CIDR snapshot (D-12) matched with a stdlib `bisect` range lookup.

Purpose: Deliver the enrichment foundation BEFORE the detectors (front-loads the false-positive risk research flagged as the milestone's biggest). The module is fully independent — it takes an IP string and returns a dict, touching no database and no request context.
Output: `backend/agent_asn_service.py`, the vendored `backend/data/vpn_ranges/x4bnet_vpn_ipv4.txt` snapshot, and `backend/tests/test_agent_asn_service.py`.
</objective>
