<objective>
Wire the three new CSPM ingest functions into `cloud_accounts_service.scan_account()`'s existing if/elif ladder so a real scan imports findings before `run_checks()` evaluates them — closing the end-to-end path for CSPM-01/02/03 (RESEARCH Pitfall 2).

Purpose: This is the single connection point where a tenant's decrypted credentials, `account_id`, and `tenant_id` are all in scope. Without these branches the catalogs (41-01) and ingest functions (41-03) never actually run together, and every result stays simulated. This plan depends on 41-01 (RUNNABLE_PROVIDERS must accept the providers or `run_checks()` errors) and 41-03 (the poll functions must exist to import).

Output: three new `elif` branches in `scan_account()` and new end-to-end scan tests in `test_cloud_accounts.py`.
</objective>
