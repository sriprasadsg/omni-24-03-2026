<objective>
Create the three provider check-definition catalogs (OCI, Alibaba, Cloudflare) and wire them into the single load-bearing execution gate in `cloud_checks_service.py` so `run_checks()` actually evaluates them.

Purpose: This is the "checks are no longer allowlisted-but-inert" core of CSPM-01/02/03 and the ROADMAP success criterion 4. It also delivers D-05 (compliance-score contribution): the CSPM summary/coverage aggregation reads `cloud_check_results` generically with no provider filter, so widening `RUNNABLE_PROVIDERS` + adding the checks to `CLOUD_CHECKS` is the entire D-05 change — the tenant-wide `compliance_score_endpoints.py` reads `asset_compliance`, not cloud check results, so no separate allowlist exists there (Open Question 1 resolved during planning).

Output: `cloud_checks_oci.py`, `cloud_checks_alibaba.py`, `cloud_checks_cloudflare.py`, an updated `cloud_checks_service.py`, and extended/repaired tests in `test_cloud_checks_expansion.py`.
</objective>
