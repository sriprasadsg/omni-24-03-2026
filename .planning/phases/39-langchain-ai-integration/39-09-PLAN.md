Migrate narrative generation (executive summaries + per-framework findings narratives embedded in PDF reports) onto create_agent with the NarrativeOutput structured output, preserving the existing word-budget validation, the prompt-injection sanitization, and — critically — the fail-closed fallback that never lets report generation hard-fail. The public functions and `enrich_report_data` orchestration are preserved by a shim so `scheduled_reports_service` and the reportlab render path are untouched (CONTEXT.md).

Purpose: Bring narrative generation onto the shared structured-output + guardrail + tracing envelope, collapsing another hand-rolled generate_text path, without risking the scheduled-report pipeline that embeds its output in auditor-facing PDFs.
Output: agents/narrative.py, the compliance_narrative_service.py shim, and agent unit tests.
</objective>
