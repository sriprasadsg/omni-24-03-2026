| Boundary | Description |
|----------|-------------|
| LLM finding → Mongo asset_compliance | Model output untrusted until schema-validated + citation-resolved |
| fallback model → pass finding | Degraded-model output must be visibly degraded, never silently equal |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-39-06-A | Tampering | Fabricated citation / control_id (Failure Mode 2) | mitigate | response_format AuditFinding (citations min_length=1) + validate_citations wired into the call path; downgrade on failure |
| T-39-06-B | Repudiation | Fail-open scoring on error | mitigate | Fail-closed shim: exceptions/downgrades return verified False, never a fabricated pass |
| T-39-06-C | Information Disclosure | Cross-tenant evidence in finding | mitigate | Tenant-closed tools + cross_tenant_output_scan post-hook |
| T-39-06-D | Spoofing | Silent fallback degradation (Failure Mode 5) | mitigate | model_provenance stamped; fallback pass -> needs_review escalation |
</threat_model>
