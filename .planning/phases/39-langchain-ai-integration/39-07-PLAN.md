| tenant conversation memory → checkpointer | thread_id must be tenant-prefixed or memory leaks across tenants |
| agent answer → user | Cross-tenant identifiers must not appear in the answer |

| T-39-07-B | Information Disclosure | Cross-tenant data in chat answer | mitigate | Tenant-closed retrieval tool + cross_tenant_output_scan post-hook |
| T-39-07-C | Tampering | Prompt injection via user input | mitigate | scan_input PII/injection hook before external model call |
