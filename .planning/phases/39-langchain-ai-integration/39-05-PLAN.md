<objective>
Build the shared agent substrate every surface migration (39-06..09) depends on: the tenant-scoped retrieval and evidence @tool factories (closing tenant_id over the closure, never model-supplied — the structural mitigation for Critical Failure Mode #1 cross-tenant leakage), the versioned prompt constants, and the online guardrail hooks that wrap every agent ainvoke (AI-SPEC Section 6). This is the connective tissue that keeps the four create_agent call sites DRY and keeps the tenant-isolation + guardrail invariants in one place instead of four.

Purpose: One tool factory, one guardrail hook set, one prompt registry — so the four agent plans wire behavior, not re-derive it, and the tenant-closure + guardrail rules cannot drift per surface.
Output: tools/retrieval.py, tools/evidence.py, prompts.py, guardrails.py, and hermetic unit tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model → retrieval tool args | If tenant_id were a tool parameter, a prompt-injected doc could redirect retrieval to another tenant |
| retrieved evidence → agent output | Injection instructions embedded in evidence must not reach the system prompt or bypass output scan |
| agent output → user/persistence | Cross-tenant identifiers in output are a confidentiality incident, not a quality bug |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-39-05-A | Elevation of Privilege | Tenant filter as model-supplied tool arg | mitigate | tenant_id closed over in factory; test asserts args schema exposes only query; grep-gate forbids get_tenant_id in tool bodies |
| T-39-05-B | Information Disclosure | Cross-tenant identifier in agent output | mitigate | cross_tenant_output_scan blocks + flags as security incident (Section 6 block+page) |
| T-39-05-C | Tampering | Prompt injection via retrieved evidence | mitigate | evidence arrives as tool output, never interpolated into system prompt (Section 4b) |
</threat_model>
