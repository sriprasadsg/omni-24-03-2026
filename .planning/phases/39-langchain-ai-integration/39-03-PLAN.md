<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM output → backend persistence | Model-produced findings/answers are untrusted until schema-validated and citation-resolved |
| finding.control_id → framework registry | Model-supplied control IDs must match seeded frameworks or be rejected |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-39-03-A | Tampering | Fabricated citation IDs (Failure Mode 2) | mitigate | validate_citations resolves every id against real tenant evidence; unresolvable -> downgrade to insufficient_evidence |
| T-39-03-B | Tampering | Invented control IDs (framework fidelity) | mitigate | control_id resolved against db.compliance_frameworks registry; regex token sweep of free text |
| T-39-03-C | Information Disclosure | Cross-tenant evidence resolution | mitigate | validator queries are tenant-scoped + global only; no unfiltered evidence reads |
</threat_model>
