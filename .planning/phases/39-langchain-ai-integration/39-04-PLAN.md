## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| tenant conversation state → checkpointer | thread_id must be tenant-prefixed or memory leaks across tenants |
| backend → Phoenix OTLP | Spans carry tenant evidence text; must stay self-hosted |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-39-04-A | Information Disclosure | Shared conversation memory across tenants | mitigate | Mandatory tenant-prefixed thread_id in make_thread_id; test asserts distinct ids per tenant |
| T-39-04-B | Tampering | Duplicate provider cache with divergent invalidation | mitigate | Reuse ai_service.invalidate_tenant_provider; grep-gate forbids a second _tenant_providers cache |
| T-39-04-C | Denial of Service | Tracing failure blocking startup | accept | Graceful try/except degrade mirrors existing Anthropic instrumentor; startup never blocks on tracing |
</threat_model>
