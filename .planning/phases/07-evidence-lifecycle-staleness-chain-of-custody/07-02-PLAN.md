<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → settings PATCH | Untrusted thresholdDays integer crosses into persisted tenant config |
| client → CoC GET | Untrusted evidence_id / control_id; response must not leak other tenants' audit trail |
| endpoint → evidence_audit_log | Read-only query into the immutable audit collection |

## STRIDE Threat Register

| ID | Threat | Severity | Mitigation |
|----|--------|----------|------------|
| T-07-05 | Cross-tenant CoC disclosure (Information Disclosure) | High | Every CoC query adds `query["tenantId"] = tenant_id` for non-super callers; a non-super caller with no tenant_id gets 403. Verified by `test_coc_tenant_isolation`. |
| T-07-06 | Unauthorized threshold modification (Elevation of Privilege) | High | PATCH calls `_require_admin(current_user)`; non-admin → 403. Verified by `test_patch_staleness_requires_admin`. |
| T-07-07 | Threshold value injection / out-of-range (Tampering) | Med | `StalenessThresholdUpdate.thresholdDays: int = Field(ge=1, le=365)` → 422 on 0/400 or non-int. Verified by `test_staleness_threshold_validation`. |
| T-07-08 | CoC entry written for an evidence op that failed (Repudiation/integrity) | Med | `_append_coc_entry` is called only after the mutation `await` returns successfully (Pitfall 2); fire-and-forget so a CoC failure cannot fake or block the op. |
| T-07-09 | Router silently fails to load, disabling tenant isolation endpoint (Denial of Service) | Med | `compliance_evidence_lifecycle_endpoints` added to `_REQUIRED_ROUTERS` so a load failure fails startup fast rather than serving without the endpoints. |
</threat_model>
