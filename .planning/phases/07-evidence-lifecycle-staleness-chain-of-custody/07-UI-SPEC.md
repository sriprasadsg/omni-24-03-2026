## Component Contracts

### 1. Stale Evidence Badge

**Location:** `components/AssetComplianceList.tsx` — inside each automated evidence row, rendered alongside the existing "Automated" source badge.

**Trigger:** Evidence record has `stale: true` (field set by backend staleness evaluation, STALE-01).

**Visual:**
```
[Automated] [Stale]
```
- Pill badge: `px-1.5 py-0.5 text-xs font-semibold rounded-full`
- Light mode: `bg-amber-100 text-amber-700`
- Dark mode: `dark:bg-amber-900/30 dark:text-amber-300`
- Icon: `ClockIcon` at size 10, `mr-0.5`, inline before the text "Stale"
- Placed immediately after the "Automated" badge in the `flex items-center gap-1` badge group
- Only rendered when `ev.stale === true` — never shown for manual evidence

**Interaction:** Non-interactive. No click, no tooltip required. The badge itself communicates the state. Staleness age detail (how many days old) is display-only text appended to the evidence name as a parenthetical: `Evidence Name (14 days old)` — only when stale, using `ev.stale_days` if provided.

**States:**
| State | Rendered |
|-------|----------|
| Fresh automated evidence | "Automated" badge only |
| Stale automated evidence | "Automated" badge + "Stale" badge + days-old parenthetical |
| Manual evidence (any age) | "Manual" badge only — staleness not applied |

### 2. Staleness Threshold Settings Control

**Location:** `components/SettingsDashboard.tsx` — new "Evidence" tab (or section within an existing relevant tab). Based on existing tab pattern: add a new `SettingsView` value of `'evidence'` and a corresponding tab nav entry.

**Placement:** New tab labeled "Evidence" with a `ClockIcon` icon, inserted between existing tab entries. Position after "Security" tab in the left-hand nav list.

**Control anatomy:**

```
[ Evidence Quality ]          <- section heading, text-sm font-bold text-gray-900 dark:text-white

Staleness Threshold
How many days before automated evidence is flagged as stale.
[ 7 ] days                   <- number input + "days" unit label inline

[ Save ]
```

**Input field:**
- Type: `<input type="number" min="1" max="365" />`
- Width: `w-24` (6rem) — compact, as value is always 1–3 digits
- Styling: `px-3 py-2 rounded-md border border-gray-300 dark:border-gray-600 bg-white dark:bg-gray-700 text-sm text-gray-900 dark:text-gray-100`
- Matches existing DatabaseSettings/LlmSettings input field pattern exactly
- Unit label: `<span class="ml-2 text-sm text-gray-500 dark:text-gray-400">days</span>` — rendered inline after the input
- Layout: `flex items-center` row containing input + unit label

**Validation (inline):**
- Min 1, max 365 enforced via `min` / `max` HTML attributes and JS validation before save
- If value is outside range on blur: show `<p class="mt-1 text-xs text-red-600 dark:text-red-400">Must be between 1 and 365 days.</p>`
- Save button disabled when value is out of range: `disabled:opacity-50 disabled:cursor-not-allowed`

**Save button:**
- Label: "Save Threshold"
- Style: `px-4 py-2 text-sm font-medium text-white bg-primary-600 hover:bg-primary-700 rounded-md`
- Matches existing "Add Control" / "Upload Evidence" primary button pattern
- Loading state: spinner `animate-spin` SVG replaces icon, label changes to "Saving..."

**Success/error feedback:**
- On save success: `showToast('Staleness threshold updated', 'success')` — uses existing `showToast` utility
- On save error: `showToast('Failed to save threshold — please try again', 'error')`

### 3. Chain-of-Custody Log Panel

**Location:** `components/FrameworkDetail.tsx` — rendered inside the expanded control row (`expandedControlId === control.id`), below the `<AssetComplianceList />` component.

**Permission gate:** Only rendered when `hasPermission('audit:read')` returns true.
Pattern matches existing `canManageEvidence` gate: `const canViewCoC = hasPermission('audit:read');`

**Panel anatomy:**

```
+--------------------------------------------------+
| [v] Chain of Custody  (N events)   [collapse ^]  |  <- header, always visible
+--------------------------------------------------+
| [hidden when collapsed]                          |
|  2026-06-20 14:33 UTC                            |
|  admin@tenant.com created evidence               |
|  Evidence ID: ev_abc123                          |
|                                                  |
|  2026-06-19 09:12 UTC                            |
|  agent-collector updated evidence                |
|  Evidence ID: ev_abc123                          |
|  Change: content updated                         |
+--------------------------------------------------+
```

**Header row:**
- Container: `flex items-center justify-between px-4 py-2 bg-gray-100 dark:bg-gray-700/50 rounded-t-md border border-gray-200 dark:border-gray-700 cursor-pointer`
- Left: `<span class="text-sm font-semibold text-gray-700 dark:text-gray-300 flex items-center gap-1.5"><ClockIcon size={14} /> Chain of Custody <span class="text-xs font-normal text-gray-400">({count} events)</span></span>`
- Right: chevron icon (`ChevronDownIcon` / `ChevronUpIcon`, size 14) indicating expand/collapse state
- Clicking header toggles `isCoCExpanded` state (local `useState<boolean>(false)`)

**Log body (visible when expanded):**
- Container: `border border-t-0 border-gray-200 dark:border-gray-700 rounded-b-md divide-y divide-gray-100 dark:divide-gray-700/50 bg-white dark:bg-gray-800`
- Each log entry: `px-4 py-3`

**Log entry structure:**
```tsx
<div className="px-4 py-3">
  <div className="flex items-start gap-2">
    <div className="flex-shrink-0 mt-0.5">
      {/* action-type icon, size 14 */}
    </div>
    <div className="min-w-0">
      <p className="text-xs font-semibold text-gray-800 dark:text-gray-200">
        {actor} <span className="font-normal text-gray-500">{actionLabel}</span>
      </p>
      <p className="text-xs text-gray-400 dark:text-gray-500 mt-0.5">
        {timestamp} UTC · Evidence {evidenceId}
      </p>
      {/* snapshot diff — only for update actions */}
      {action === 'update' && snapshot && (
        <details className="mt-1">
          <summary className="text-xs text-gray-400 cursor-pointer hover:text-gray-600 dark:hover:text-gray-300">
            Show change
          </summary>
          <pre className="mt-1 text-xs text-gray-600 dark:text-gray-400 bg-gray-50 dark:bg-gray-700/50 p-2 rounded overflow-x-auto whitespace-pre-wrap break-words">
            {JSON.stringify(snapshot, null, 2)}
          </pre>
        </details>
      )}
    </div>
  </div>
</div>
```

**Action-type icons (use existing icon set):**
| Action | Icon | Color |
|--------|------|-------|
| `create` | `PlusIcon` size 14 | `text-green-600 dark:text-green-400` |
| `update` | `RefreshCwIcon` size 14 | `text-blue-600 dark:text-blue-400` |
| `delete` | `TrashIcon` size 14 | `text-red-500 dark:text-red-400` |

**Action labels (human-readable):**
| action_type | Displayed as |
|-------------|-------------|
| `create` | "uploaded evidence" |
| `update` | "updated evidence" |
| `delete` | "deleted evidence" |

**Timestamp format:** ISO string from backend, rendered via `new Date(ts).toLocaleString('en-US', { timeZone: 'UTC', year: 'numeric', month: 'short', day: 'numeric', hour: '2-digit', minute: '2-digit' })` → e.g. "Jun 20, 2026, 14:33 UTC"

**Empty state (no log entries):**
```
<p className="px-4 py-6 text-center text-xs text-gray-400 italic">
  No chain-of-custody events recorded for this evidence.
</p>
```

**Loading state:**
- Spinner centered in panel body while fetching: `<div className="flex justify-center py-4"><svg className="animate-spin h-4 w-4 text-gray-400" ... /></div>`

**Error state:**
- `<p className="px-4 py-4 text-xs text-red-500">Failed to load audit log. Retry by collapsing and expanding this panel.</p>`

**Permission-denied state (user lacks audit:read):**
- Panel is entirely absent from the DOM — no placeholder or locked state shown

## States and Interactions Summary

### Stale Badge
| Trigger | UI Response |
|---------|-------------|
| `ev.stale === true` | Amber "Stale" badge appears after "Automated" badge |
| `ev.stale === false` or field absent | No badge change |
| Manual evidence (any value of stale) | Badge never shown |

### Threshold Input
| Trigger | UI Response |
|---------|-------------|
| Value in 1–365 | Save button enabled |
| Value outside 1–365 | Inline validation error, Save button disabled |
| Save clicked | Loading state on button, toast on resolve |
| Page load | Input pre-populated from backend (`GET /api/settings/evidence-staleness`) |

### CoC Panel
| Trigger | UI Response |
|---------|-------------|
| User lacks `audit:read` | Panel absent entirely |
| Panel header clicked (collapsed) | Expand — fetch log entries, show spinner, then render entries |
| Panel header clicked (expanded) | Collapse — unmount body, panel header remains |
| Fetch fails | Error message inside panel body |
| Zero log entries | Empty state message |
