<objective>
Fix the two shared backend AI primitives so the rest of Phase 30 can retrieve tenant-safe evidence and generate low-creativity grounded answers. This is the BLOCKING prerequisite for all downstream Phase 30 drafting work: `rag_service.py`'s single global ChromaDB collection has no tenant scoping today (Critical Failure Mode #3 / threat T1 — a query for tenant A returns tenant B's evidence), and `ai_service.generate_text()` exposes no `temperature`/`max_tokens` control (hardcoded `max_tokens: 1024`, provider-default temperature ≈ 1.0), which grounded questionnaire answers require lowered/raised.

Purpose: Close the cross-tenant retrieval leak with a hard-blocking isolation test before any tenant evidence flows through RAG, and plumb generation controls so the draft service (30-04) can call with `temperature=0-0.2`, `max_tokens=1536-2048`.
Output: Tenant-scoped `rag_service.py`, a passing `test_rag_service_tenant_isolation.py`, and an extended `generate_text()`/provider signature.
</objective>
