## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → intake API | Untrusted uploaded spreadsheet + JSON question text crosses here |
| API → questionnaire_inbound collection | Tenant-scoped writes must never be cross-tenant |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-30-IV | Tampering / DoS | parse_upload() spreadsheet parsing | medium | mitigate | Length-cap + control-char strip question text (V5); reject ambiguous column layout with 400 instead of guessing; use `read_only=True` streaming workbook load |
| T2 | Information Disclosure | questionnaire_inbound collection reads | high | mitigate | All reads/writes go through `get_database()`/`TenantIsolatedCollection` auto tenant scoping; collection is NOT added to any global-exemption allowlist |
</threat_model>
