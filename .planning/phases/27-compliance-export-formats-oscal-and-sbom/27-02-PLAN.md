<objective>
Add a read-only CycloneDX 1.6 SBOM export (EXP-02) for scanned container images by adding
one GET route to the existing `container_scanner_endpoints.py`, transforming a stored
`container_scan_results` document's `vulns` list into a Software Bill of Materials, plus a
frontend "Export SBOM" button.

Purpose: SBOM export for scanned container images is table-stakes "audit-ready" output; it
lets downstream vulnerability-management/GRC tooling ingest the platform's container scan
data in a standard machine-readable format.

Output: New `_to_cyclonedx` builder + `GET /results/{scan_id}/sbom` route inside the
existing container-scanner module, its test file, and an "Export SBOM" button on
`IacContainerDashboard.tsx`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → /api/container/results/{scan_id}/sbom | Authenticated but potentially cross-tenant caller supplies `scan_id`; response must be scoped to caller's tenant |
| simulated scan data → exported SBOM | Synthetic Trivy-fallback data must not be presented as authoritative compliance evidence |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-27-03 | Information Disclosure | `container_scanner_endpoints.container_result_sbom` | high | mitigate | Query the raw `db._db.container_scan_results` with an explicit `{"scan_id": scan_id, "tenantId": get_tenant_id()}` filter; a wrong-tenant or nonexistent scan_id both return an identical 404 (no enumeration leak). Verified by `test_container_sbom_export.py -k tenant`. |
| T-27-02 | Spoofing (assessment authenticity) | `_to_cyclonedx` simulated handling | medium | mitigate | Surface `simulated` in CycloneDX `metadata.properties` (`omniagent:simulated="true"`) per resolved decision #2 so downstream consumers know the data is synthetic; export is not silently authoritative. Verified by `test_container_sbom_export.py -k simulated`. |
| T-27-04 | Tampering | CycloneDX JSON string fields (pkg names, CVE titles/descriptions) | low | accept | Builder returns a dict serialized by FastAPI's default JSON encoder (never string concatenation); JSON has no formula auto-execution. No extra sanitization needed. |
| T-27-SC | Tampering | pip installs | high | accept | No new package installs this phase — CycloneDX document is hand-rolled with stdlib (`uuid`); matches existing `sbom_endpoints.py` hand-parse precedent. `cyclonedx-python-lib` flagged SUS and rejected; no install task exists, so no blocking-human checkpoint required. |
</threat_model>
