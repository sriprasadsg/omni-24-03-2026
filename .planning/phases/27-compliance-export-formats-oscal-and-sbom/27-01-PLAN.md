<objective>
Add a read-only OSCAL export endpoint (EXP-01) that transforms existing compliance
control/evidence data into a structurally-valid OSCAL v1.1.2 `assessment-results` JSON
document, plus a frontend button to download it.

Purpose: Machine-readable OSCAL is table-stakes "audit-ready" output flagged by the
awesome-compliance audit; it lets downstream GRC tooling ingest this platform's control
assessment results without screen-scraping the PDF/CSV.

Output: New `backend/oscal_endpoints.py` (thin GET endpoint + pure dict builder), its
test file, one router-registry line, and an "Export OSCAL" button on
`ApiExtensionsDashboard.tsx`.
</objective>
