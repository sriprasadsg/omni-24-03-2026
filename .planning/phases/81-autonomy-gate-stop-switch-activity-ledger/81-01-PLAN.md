<objective>
Build the code-owned safety core of Autonomous Ops as a new package `backend/autonomous_ops/`: the action registry (with the GATE-04 raise-only rule pinned against the shipped playbooks), per-tenant settings reads (level, maximum level, shadow, stop, eligibility), the decision ledger with compare-and-set transitions and an awaited audit mirror, and the gate (`decide`, `suggest`, `execute`, `execute_response_task`) with its ordered step structure, the eligibility, class and shadow steps and the write-ahead intent row. 81-11 (wave 2) completes the decision order in the same gate: never-touch list, host cap, rate limit, dedupe/cooldown/suppression, stop and level steps, the strings module and the exhaustive enumeration. The decision core was split across 81-01 and 81-11 so each plan fits the executor's context budget. Nothing calls the gate until 81-11 is done (callers arrive in 81-04, 81-06, 81-08, which depend on 81-11), so the phase stays inert.

Purpose: GATE-03 requires one ordered decision function that every autonomous action passes and that is the only writer of autonomous instructions; GATE-07 requires the intent record to exist before any dispatch; GATE-04 requires the locked split (block IP, quarantine file, restart service automatic) to hold while a playbook may only raise a class. Every later plan in this phase consumes the interfaces fixed here.
Output: six package modules (each under 500 lines), three test modules and the shared test fixture module.
</objective>
