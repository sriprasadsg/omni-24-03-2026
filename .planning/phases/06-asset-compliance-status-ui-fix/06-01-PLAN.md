<action>
Create `backend/compliance_status_endpoints.py` with:

Imports: `from fastapi import APIRouter, HTTPException, Depends`; `from pydantic import BaseModel`; `from typing import Literal`; `from datetime import datetime, timezone`; `from database import get_database`; `from authentication_service import get_current_user`

Constants: `_SUPER_ROLES = {"Super Admin", "super_admin", "admin", "platform-admin"}`; `_VALID_STATUSES: set[str] = {"Compliant", "Non-Compliant", "Pending_Evidence"}`

Request body model:
```
class ComplianceStatusUpdate(BaseModel):
    control_id: str
    status: Literal["Compliant", "Non-Compliant", "Pending_Evidence"]
    notes: str = ""
```

Endpoint signature: `@router.patch("/api/assets/{asset_id}/compliance/status")` / `async def patch_asset_compliance_status(asset_id: str, body: ComplianceStatusUpdate, current_user=Depends(get_current_user))`

Body logic:
1. Extract `user_role = getattr(current_user, "role", "")`, `actor = getattr(current_user, "username", "unknown")`, `tenant_id = getattr(current_user, "tenant_id", None) or ""`
2. If `user_role not in _SUPER_ROLES`: call `await db.assets.find_one({"id": asset_id, "tenantId": tenant_id})`, raise `HTTPException(status_code=403, detail="Asset not found in your tenant")` if None
3. Fetch current doc: `doc = await db.asset_compliance.find_one({"assetId": asset_id, "controlId": body.control_id, "tenantId": tenant_id})`; `previous_status = doc.get("status", "Unknown") if doc else "Unknown"`
4. `now = datetime.now(timezone.utc)`
5. `await db.asset_compliance.update_one({"assetId": asset_id, "controlId": body.control_id, "tenantId": tenant_id}, {"$set": {"status": body.status, "lastUpdated": now.isoformat(), "manual_override": True, "overriddenBy": actor, "overriddenAt": now.isoformat()}, "$push": {"status_history": {"status": body.status, "changedBy": actor, "changedAt": now.isoformat(), "previous_status": previous_status, "notes": body.notes}}}, upsert=True)`
6. Return `{"ok": True, "status": body.status, "previous_status": previous_status}`
</action>
