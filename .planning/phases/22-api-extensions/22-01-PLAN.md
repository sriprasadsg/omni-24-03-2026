<objective>
Implement four API extension features identified in the audit as differentiating gaps versus the reference projects:

**1. MCP Protocol Server** — expose compliance data via Model Context Protocol so AI assistants can query the platform directly.

MCP tool execution pattern:
```
POST /api/mcp/execute/get_compliance_score
{"framework": "soc2", "tenant_id": "..."}
→ {"score": 87, "passing": 124, "total": 143, "framework": "soc2"}
```

**2. OCSF Output Format** — Open Cybersecurity Schema Framework output so findings can feed into SIEMs directly.

OCSF Finding format (class 2004):
```json
{
  "class_uid": 2004,
  "category_uid": 2,
  "type_uid": 200401,
  "severity_id": 3,
  "finding": {"title": "...", "uid": "..."},
  "time": 1719000000,
  "metadata": {"version": "1.0.0", "product": {"name": "Omni Agent Platform"}}
}
```

**3. DigitalOcean Cloud Checks** — 10 new DO-specific checks added to CLOUD_CHECKS list with provider="digitalocean".

**4. CLI Tool** — `backend/scripts/omni-cli.py` using Click framework:
```bash
python omni-cli.py frameworks list
python omni-cli.py scan cloud --provider digitalocean --account-id 12345
python omni-cli.py findings list --severity high --limit 10
python omni-cli.py score --framework soc2
```

CLI uses `OMNI_API_URL` and `OMNI_API_TOKEN` environment variables.

- "MCP Tools" section: table of tool name, description, params example
- "OCSF Export" section: two download buttons (findings, cloud-checks) with format badge
- "DigitalOcean" section: account setup guide + check list
- "CLI Quickstart" section: code block with install + usage examples

Output: 4 files (+ 1 in scripts/), all endpoints functional, CLI executable
</objective>
