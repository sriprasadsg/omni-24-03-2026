<objective>
Route every plan change through one function (D-13, D-25): the Super Admin's tenant PATCH, the create route's screen check, and the payment route, which from now on only records a subscription (D-39). The Super Admin's screen ticks are limited by the plan only (D-40, D-27, D-28), and a drift guard keeps future code from writing subscriptionTier anywhere else.

Purpose: before this plan, a tenant user with manage:settings could set any plan string through the payment route, and the Super Admin PATCH validated nothing; with plans now deciding seats and screens both would be privilege problems.
Output: change_plan, the tenant route edits, the payment route edits, and two test modules.
</objective>
