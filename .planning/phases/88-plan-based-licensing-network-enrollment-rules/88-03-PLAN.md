Seed algorithm (D-29; reproduces the research counts 19/69/120, verified during planning):
1. Catalogue tier of a permission = the lowest minTier (Free 0, Pro 1, Enterprise 2) among feature_catalog.FEATURE_CATALOG entries with that permission.
2. Own tier of a switch, first rule that applies: (A) the switch key is a catalogue permission; (B) for screen:<view>, tenant_features.SCREEN_SWITCHES[view] (the permission its manifest entry needs) is a catalogue permission; (C) for screen:<view>, a catalogue key whose lower-cased letters and digits equal the view's lower-cased letters and digits (18 matches, 9 not already covered).
3. Final tier = own tier raised to at least the parent's final tier (tenant_features.SWITCH_PARENTS); no own tier -> the parent's final tier; no parent either -> Enterprise.
4. Lists are cumulative: Free = tier 0, Pro = tier 0..1, Enterprise = every switch. Each list sorted.
</context>
