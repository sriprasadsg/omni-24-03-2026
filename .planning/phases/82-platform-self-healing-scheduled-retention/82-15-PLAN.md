<objective>
Close CR-01, the phase's one data-loss path. Adoption stops keying on when the job first saw a row and keys on when the tenant was created, read through one fail-closed helper. `run_all` guards each tenant and always leaves a run record. A confirmation is refused while the counted set is incomplete.

Purpose: HEAL-06 says the first run is a dry-run count the operator confirms; today a tenant missed by an interrupted first pass is deleted with no count and no confirmation, nightly and through POST /api/retention/run (T-82-33, T-82-36). HEAL-07: a run that failed a tenant must say so in platform Activity.
Output: changes to `retention_gate.py`, `retention_job.py` and the review routes, one new regression test module, and the tests that encoded the old rule.

The `incomplete` field added to GET /review is consumed by 82-17.
</objective>
