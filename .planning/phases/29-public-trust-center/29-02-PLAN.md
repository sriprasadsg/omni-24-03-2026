<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| external visitor (no auth) → public API | Untrusted, unauthenticated input crosses here: slug, Host header, and the access-request body are all attacker-controllable |
| public handler → db.tenants (exempt) | Tenant is resolved from a public identifier against the exemption-allowlisted tenants collection BEFORE any tenant context is set |
| public handler → tenant-scoped collections | trust_profiles/trust_access_requests are queried only AFTER set_tenant_id(tenant["id"]) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Status | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|--------|-----------------|
| T-29-01 | Information Disclosure | public GET/POST tenant resolution | high | mitigate | closed | Resolve tenant via exempt db.tenants + explicit `set_tenant_id()` before any tenant-scoped query (Pattern 2/Pitfall 1); NEVER add trust_profiles/trust_access_requests to database.py's allowlist. Verified `-k public_get`, `-k tenant`. |
| T-29-03 | Information Disclosure | _public_view / public GET response | high | mitigate | closed | Server-side `_public_view` strips `private_documents` to name-only stubs (no `url`) — enforced server-side, not by UI tab choice (Pitfall 3). Verified `-k private_doc_filter`. |
| T-29-02 | Information Disclosure (slug enumeration/scraping) | GET /api/public/trust/{slug} | medium | mitigate | closed | `@limiter.limit("30/minute")` IP-keyed; identical 404 "Not found" for unknown-slug and no-profile (no existence leak via differing messages); trust_slug is an opaque `trust-{uuid4().hex[:12]}` independent of tenant id. | T-29-04 | Tampering / Spoofing | public POST access-request metadata | medium | mitigate | closed | `ip_address`/`user_agent`/`requested_at` are server-derived from `request.client.host`/headers/`utcnow`, never from the body; only requester_email/company/reason/consent (inherently self-reported, human-validated at approval) come from the body.
