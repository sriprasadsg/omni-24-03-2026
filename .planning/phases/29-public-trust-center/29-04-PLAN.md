## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| external browser → static page | Unauthenticated visitor loads the page; the page itself carries no secrets and is served identically to every visitor |
| page JS → public API | The page's fetch() consumes only the 29-02 `_public_view` response — which has already stripped private document URLs server-side |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Status | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|--------|-----------------|
| T-29-03 | Information Disclosure | restricted-document rendering in trust-page.html | high | mitigate | closed | The page renders `private_documents` as name-only stubs and NEVER derives an `href`/`url` from them; it relies on the server-side `_public_view` (29-02) which omits the url. Enforced by the negative grep in this plan's verify. |
| T-29-02 | Information Disclosure (existence leak) | 404 / unknown-slug state | low | mitigate | closed | Unknown slug renders the generic "Trust page not found." copy — no differentiation between "no such tenant" and "tenant has no profile" (the server already returns an identical 404). |
| T-29-08 | Denial of Service / abuse | public request form submission | low | transfer | closed | Client-side consent + email validation reduces junk submissions; the authoritative rate limit and consent enforcement live server-side (29-02 `@limiter.limit("5/minute")`) — the page surfaces the 429 banner copy but does not implement limiting itself. |
| T-29-SC | Tampering | third-party font CDN (Google Fonts) | low | accept | closed | The only external reference is the Outfit font `<link>` (UI-SPEC-mandated for brand parity). No npm/pip/cargo installs; no executable third-party script is loaded. |
