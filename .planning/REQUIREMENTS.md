# Requirements: ITAM-Backlog (Backlog Expansion)

**Defined:** 2026-08-12
**Goal:** Address the identified gaps between the current ITAM Console and Snipe-IT.

## ITAM-Backlog Requirements

### 1. User Management & Authentication

- **ITAM-USR-01**: User CRUD.
- **ITAM-USR-02**: Role-Based Access Control (RBAC).
- **ITAM-USR-03**: LDAP/Active Directory Integration.
- **ITAM-USR-04**: SAML/SSO Authentication.
- **ITAM-USR-05**: API Access Token Management.
- **ITAM-USR-06**: Two-Factor Authentication (2FA).

### 2. Core Data & Audit Features

- **ITAM-DAT-01**: Custom Fields Engine for assets.
- **ITAM-DAT-02**: Audit Trail / Activity Log for entities.
- **ITAM-DAT-03**: Bulk CSV Import/Export.

### 3. Reporting & Dashboards

- **ITAM-REP-01**: Custom Report Builder.
- **ITAM-REP-02**: Pre-built Reports for asset/license data.
- **ITAM-REP-03**: Export support (PDF, CSV, Excel).
- **ITAM-REP-04**: ITAM Dashboard with KPIs/Visualizations.

### 4. Procurement & Workflow

- **ITAM-PRO-01**: Purchase Order, Cost, and Supplier tracking.
- **ITAM-PRO-02**: Warranty tracking + automated alerts.
- **ITAM-PRO-03**: Straight-line Depreciation modeling.
- **ITAM-PRO-04**: Asset Request + Approval Workflow.
- **ITAM-PRO-05**: Alerts/Notifications (Email/Slack).

### 5. API & Integrations

- **ITAM-API-01**: Full REST API coverage for ITAM.
- **ITAM-API-02**: Webhook system for events.
- **ITAM-API-03**: Third-party integrations (Jira, ServiceNow).

### 6. Settings & Customization

- **ITAM-SET-01**: Global Settings UI.
- **ITAM-SET-02**: Branding/Theming (Logo, Colors).
- **ITAM-SET-03**: Localization/Translation support.
